# Dependency Cleanup Safety Rule

Some dependencies in this project are flagged as "unused" by automated tools like `cargo-machete` but are actually required for correctness, public API stability, or macro-generated code.

## Critical Dependencies

The following dependencies must **NEVER** be removed from their respective `Cargo.toml` files, even if they appear unused:

- **duckdb** in `crates/budget/root/Cargo.toml`: It provides optional features (`bundled_db`, `all_with_db`) that are part of the public API and are documented for end-users. Removing it or these features is a breaking change.
- **bon** in `setup/github/Cargo.toml`: While not directly used in the source files, it is required by code generated by `pulumi_gestalt_rust` macros during the build process.
- **serde_yaml** (anywhere): Must be pinned exactly to `0.9.34+deprecated` as specified in `AGENTS.md`.

## Verification Procedure

Before removing any dependency flagged as "unused":
1. Check if it is used in any `build.rs` files.
2. Check if it is required by macro-generated code (e.g., `include_provider!`).
3. Check if it is part of a public-facing feature in a facade crate (like `budget/root`).
4. Always run a full build of the affected crate, including tests with `--all-features`.
